# 🏋️‍♂️ FitLog — Workout Library & Daily Planner

FitLog is a modern, dark-themed fitness companion web app built with Next.js and Tailwind CSS. It helps gym enthusiasts explore workouts, log daily training plans, and track progress effortlessly.

🔗 **Live Demo:** [https://fit-log-eight-phi.vercel.app/](https://fit-log-eight-phi.vercel.app)

---

## ✨ Features

- **Workout Library:** Browse exercises targeting every major muscle group.
- **Dynamic Exercise Details:** View detailed specifications (sets, reps, duration, calories, instructions).
- **Today's Plan & Saved Lists:** Add exercises to your current workout routine or save them for later.
- **Smart Analytics:** Automatically calculates total exercises, total duration (minutes), and calories burned.
- **Sorting & Filtering:** Sort workouts by duration, calories, or rating.
- **Interactive Feedback:** Real-time toast notifications for adding, removing, or duplicate prevention.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **State Management:** React Context API
- **Deployment:** Vercel
